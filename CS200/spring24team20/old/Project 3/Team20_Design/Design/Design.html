Paragraph

The ideal design for any system has high cohesion and low coupling. Therefore, this was one of the goals for our diagrams. This was challenging as the ChocAn System had many unique tasks that it accomplishes. To overcome this we made sure that each class was independent, including functions that avoid variables and that could only be used in one instance. The class diagram was made with specific classes so functions were highly organized and relevant. This helped to decrease coupling and increase cohesion within the overall system. The sequence diagrams were made with direct correlation to the class diagram and its functions. Each diagram was made as concisely as possible, while including all the information that will be needed when we write the code for this program. This was all done to help us with Project 4 and to make the final system efficient and accurate.
