Estimation Paragraph

The ChocAn’s system interacts with the Provider Terminal and Acme Accounting Services. Acme updates membership status every evening at 9 PM. The Provider Terminal dials the ChocAn Data Center to validate members’ status and allows providers access to the Provider Directory. Every user will interact through their terminal. The hardware needed is the manager terminal, provider terminal, and the ChocAn Data Center, as well as a storage array to write the necessary data. The data will be stored at the ChocAn Data Center. All sections will be computerized in Java.
